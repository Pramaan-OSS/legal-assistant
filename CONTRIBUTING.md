# Contributing

Use Node 22. Install backend and frontend dependencies with npm ci --prefix backend and npm ci --prefix frontend. Run npm test and npm run build in each folder before committing. Frontend lint and typecheck run with npm run lint --prefix frontend and npm run typecheck --prefix frontend.

Tests use fake Pramaan responses. Do not add live requests, credentials, customer data or generated runtime artifacts. Describe unavailable features in the public feature documentation. Keep the licence notices and dependency acknowledgments.
